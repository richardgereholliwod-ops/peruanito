# Peruanito

Tienda web estática de accesorios de cómputo, creada para Peruanito en Miraflores, Lima.

## Ejecutar

Abre `index.html` en un navegador. No requiere dependencias ni proceso de compilación. Para servirla localmente puedes usar cualquier servidor estático.

## Contenido

- Catálogo de 12 productos con códigos, precios en soles e ilustraciones SVG originales.
- Búsqueda por categorías, bolsa persistida en el navegador, selector de vendedor y acciones de agregar, quitar, cancelar y grabar.
- Al grabar una venta, se prepara un correo dirigido a `richardgereholliwod@gmail.com` con el detalle completo. El usuario debe confirmar el envío desde su cliente de correo; una página estática no puede enviar ni verificar correos por sí sola.
- Asistente local para preguntas básicas de productos, precios, envíos, ubicación y contacto humano.
- 15 perfiles de muestra para la sección de comunidad. Son contenido demostrativo, no testimonios verificados.
- Mapa de OpenStreetMap y contacto por WhatsApp.

## Publicar en GitHub Pages

Sube el contenido de este repositorio a GitHub y habilita **Settings → Pages → Deploy from a branch**, usando la rama principal y la carpeta raíz. Al ser estático, no necesita build. El mapa requiere conexión a internet.
